The source code for my personal developer portfolio website, built from the ground up to showcase my projects, technical skills, and professional resume.

* Fully responsive custom web design (mobile and desktop).
* Dynamic project showcase section.
* Direct integration with my downloadable resume.
* Fast, lightweight, and built without heavy frameworks.
